# Official Jahan Academy logo

The official website logo is `jahan-academy-official.png`, supplied and approved by the site owner on 2026-10-03.

Use this asset for all site headers through the shared `SiteHeader` component. It supersedes `/jahan-logo.png`.
The PNG is stored byte-for-byte as supplied, including its transparent background, colors and proportions.
The header's 3:1 display frame trims only transparent vertical margins; desktop and mobile retain the full visible mark.
